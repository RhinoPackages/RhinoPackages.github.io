How to install human

  1. Click Install in Rhino to open Rhino's Package Manager with human selected, or run _PackageManager inside Rhino and search for human.On the computer running Rhino, run _PackageManager and search for human.
  2. Or install it from a terminal (assumes a default Rhino 7 installation):
    Windows (PowerShell)
    & "C:\Program Files\Rhino 7\System\Yak.exe" install human
    macOS (Terminal)
    "/Applications/Rhino 7.app/Contents/Resources/bin/yak" install human
  3. Or download a .yak file and drag it onto an open Rhino window.
    • human-1.3.1-rh7_0-any.yakWindows & Mac · Rhino 7.0

Restart Rhino once the install finishes.
