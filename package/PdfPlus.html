How to install PdfPlus

  1. Click Install in Rhino to open Rhino's Package Manager with PdfPlus selected, or run _PackageManager inside Rhino and search for PdfPlus.On the computer running Rhino, run _PackageManager and search for PdfPlus.
  2. Or install it from a terminal (assumes a default Rhino 8 installation):
    Windows (PowerShell)
    & "C:\Program Files\Rhino 8\System\Yak.exe" install PdfPlus
  3. Or download a .yak file and drag it onto an open Rhino window.
    • PdfPlus-2.1.0-rh8_0-win.yakWindows · Rhino 8.0
    • PdfPlus-2.1.0-rh7_0-win.yakWindows · Rhino 7.0
    • PdfPlus-2.1.0-rh6_0-win.yakWindows · Rhino 6.0

Restart Rhino once the install finishes.
