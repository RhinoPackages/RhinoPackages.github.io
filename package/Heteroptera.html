How to install Heteroptera

  1. Click Install in Rhino to open Rhino's Package Manager with Heteroptera selected, or run _PackageManager inside Rhino and search for Heteroptera.On the computer running Rhino, run _PackageManager and search for Heteroptera.
  2. Or install it from a terminal (assumes a default Rhino 8 installation):
    Windows (PowerShell)
    & "C:\Program Files\Rhino 8\System\Yak.exe" install Heteroptera
    macOS (Terminal)
    "/Applications/Rhino 8.app/Contents/Resources/bin/yak" install Heteroptera
  3. Or download a .yak file and drag it onto an open Rhino window.
    • Heteroptera-8.2.2-any-any.yakWindows & Mac · Any Rhino version

Restart Rhino once the install finishes.
