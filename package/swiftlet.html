swiftlet

Grasshopper plugin · v0.3.3 · updated 6/22/2026

Swiftlet is a tool that lets you call into Web APIs directly from Grasshopper. If you are interested in scraping the internet, tapping into public and private APIs or testing your own web backends, Swiftlet is a tool for you! It provides a streamlined workflow for sending GET, POST, DELETE, PUT and PATCH requests to any API endpoint. It gives you advanced control over request headers, query params, supports several kinds of web authentication and lets you parse JSON formatted web responses. Swiftlet also includes MCP (Model Context Protocol) server components for exposing Grasshopper tools to AI clients like Claude.

How to install swiftlet

  1. Click Install in Rhino to open Rhino's Package Manager with swiftlet selected, or run _PackageManager inside Rhino and search for swiftlet.On the computer running Rhino, run _PackageManager and search for swiftlet.
  2. Or install it from a terminal (assumes a default Rhino 8 installation):
    Windows (PowerShell)
    & "C:\Program Files\Rhino 8\System\Yak.exe" install swiftlet
    macOS (Terminal)
    "/Applications/Rhino 8.app/Contents/Resources/bin/yak" install swiftlet
  3. Or download a .yak file and drag it onto an open Rhino window.
    • swiftlet-0.3.3-rh8_0-any.yakWindows & Mac · Rhino 8.0

Restart Rhino once the install finishes.
