How to install human-ui

  1. Click Install in Rhino to open Rhino's Package Manager with human-ui selected, or run _PackageManager inside Rhino and search for human-ui.On the computer running Rhino, run _PackageManager and search for human-ui.
  2. Or install it from a terminal (assumes a default Rhino 8 installation):
    Windows (PowerShell)
    & "C:\Program Files\Rhino 8\System\Yak.exe" install human-ui
  3. Or download a .yak file and drag it onto an open Rhino window.
    • human-ui-0.8.10-rh8_0-win.yakWindows · Rhino 8.0

Restart Rhino once the install finishes.
