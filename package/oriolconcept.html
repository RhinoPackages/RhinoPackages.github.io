How to install oriolconcept

  1. Click Install in Rhino to open Rhino's Package Manager with oriolconcept selected, or run _PackageManager inside Rhino and search for oriolconcept.On the computer running Rhino, run _PackageManager and search for oriolconcept.
  2. Or install it from a terminal (assumes a default Rhino 8 installation):
    Windows (PowerShell)
    & "C:\Program Files\Rhino 8\System\Yak.exe" install oriolconcept
  3. Or download a .yak file and drag it onto an open Rhino window.
    • oriolconcept-1.0.0.2-rh8_34-win.yakWindows · Rhino 8.34

Restart Rhino once the install finishes.
