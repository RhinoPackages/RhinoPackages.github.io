How to install GSA

  1. Click Install in Rhino to open Rhino's Package Manager with GSA selected, or run _PackageManager inside Rhino and search for GSA.On the computer running Rhino, run _PackageManager and search for GSA.
  2. Or install it from a terminal (assumes a default Rhino 7 installation):
    Windows (PowerShell)
    & "C:\Program Files\Rhino 7\System\Yak.exe" install GSA
  3. Or download a .yak file and drag it onto an open Rhino window.
    • GSA-1.5.3-rh7_38-win.yakWindows · Rhino 7.38

Restart Rhino once the install finishes.
