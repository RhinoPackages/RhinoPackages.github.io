How to install Parakeet

  1. Click Install in Rhino to open Rhino's Package Manager with Parakeet selected, or run _PackageManager inside Rhino and search for Parakeet.On the computer running Rhino, run _PackageManager and search for Parakeet.
  2. Or install it from a terminal (assumes a default Rhino 7 installation):
    Windows (PowerShell)
    & "C:\Program Files\Rhino 7\System\Yak.exe" install Parakeet
    macOS (Terminal)
    "/Applications/Rhino 7.app/Contents/Resources/bin/yak" install Parakeet
  3. Or download a .yak file and drag it onto an open Rhino window.
    • Parakeet-1.2.0-rh7_36-any.yakWindows & Mac · Rhino 7.36
    • Parakeet-1.2.0-rh7_30-any.yakWindows & Mac · Rhino 7.30
    • Parakeet-1.2.0-rh7_0-any.yakWindows & Mac · Rhino 7.0
    • Parakeet-1.2.0-rh6_0-any.yakWindows & Mac · Rhino 6.0

Restart Rhino once the install finishes.
