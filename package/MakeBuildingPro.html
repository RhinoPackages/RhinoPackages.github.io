MakeBuildingPro

Grasshopper plugin · v5.12.0 · updated 7/30/2026

Parametric structural design plugin for Grasshopper 8 (Rhino 8+). The Speckle Connector for Rhino 8 (v3) is OPTIONAL: MakeBuildingPro loads and works without it. It is only needed for the Speckle one-way export (Comp_E06), which ships as a separate satellite plugin (MakeBuildingPro.Speckle.gha) that loads only when the connector is installed. To use Speckle export, install the connector via the Package Manager (search "Speckle") and restart Rhino. - BIM data management with Excel / CSV / JSON round-trip - Irregular plans via void cut-outs (v5.7.0): cut: syntax, bay void toggle, consistency validation (L-shape / setback) - 3D model generation (columns, beams, walls, slabs, cantilevers, braces, posts) - Structural analysis model (centerline) + STBridge exporter (SS7 / SEIN / SNAP / Midas) - 2D structural plans and section drawings - AI Building Generator (OpenAI / Anthropic / Gemini) with Diff & Approval - Speckle one-way export (optional; requires the Speckle Connector for Rhino 8) - Bundled MCP server (Experimental) for Claude Desktop / Cursor / Cline See README.md and the documentation site for setup and usage.

How to install MakeBuildingPro

  1. Click Install in Rhino to open Rhino's Package Manager with MakeBuildingPro selected, or run _PackageManager inside Rhino and search for MakeBuildingPro.On the computer running Rhino, run _PackageManager and search for MakeBuildingPro.
  2. Or install it from a terminal (assumes a default Rhino 8 installation):
    Windows (PowerShell)
    & "C:\Program Files\Rhino 8\System\Yak.exe" install MakeBuildingPro
  3. Or download a .yak file and drag it onto an open Rhino window.
    • MakeBuildingPro-5.12.0-rh8_9-win.yakWindows · Rhino 8.9

Restart Rhino once the install finishes.
