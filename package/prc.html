prc

Grasshopper plugin · v1.759.0 · updated 10/16/2026

PRC (Parametric Robot Control) is a Grasshopper plugin for intuitive robot programming and simulation. It supports industrial robots from major manufacturers - primarily KUKA, now also including ABB, Neura, and Universal Robots, enabling parametric control of robotic fabrication workflows directly within Rhino/Grasshopper. PRC is the experimental branch of KUKA|prc, not a replacement. > We provide a completely free Community Version with a slightly reduced feature-set. > To run PRC, you also need the server component that you can download from https://portal.robotsinarchitecture.org

How to install prc

  1. Click Install in Rhino to open Rhino's Package Manager with prc selected, or run _PackageManager inside Rhino and search for prc.On the computer running Rhino, run _PackageManager and search for prc.
  2. Or install it from a terminal (assumes a default Rhino 8 installation):
    Windows (PowerShell)
    & "C:\Program Files\Rhino 8\System\Yak.exe" install prc
    macOS (Terminal)
    "/Applications/Rhino 8.app/Contents/Resources/bin/yak" install prc
  3. Or download a .yak file and drag it onto an open Rhino window.
    • prc-1.759.0-rh8_0-any.yakWindows & Mac · Rhino 8.0

Restart Rhino once the install finishes.
