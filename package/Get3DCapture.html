How to install Get3DCapture

  1. Click Install in Rhino to open Rhino's Package Manager with Get3DCapture selected, or run _PackageManager inside Rhino and search for Get3DCapture.On the computer running Rhino, run _PackageManager and search for Get3DCapture.
  2. Or install it from a terminal (assumes a default Rhino 8 installation):
    Windows (PowerShell)
    & "C:\Program Files\Rhino 8\System\Yak.exe" install Get3DCapture
  3. Or download a .yak file and drag it onto an open Rhino window.
    • Get3DCapture-1.0.7-rh8_0-win.yakWindows · Rhino 8.0
    • Get3DCapture-1.0.7-rh7_0-win.yakWindows · Rhino 7.0

Restart Rhino once the install finishes.
