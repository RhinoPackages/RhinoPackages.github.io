How to install ArchiHacks

  1. Click Install in Rhino to open Rhino's Package Manager with ArchiHacks selected, or run _PackageManager inside Rhino and search for ArchiHacks.On the computer running Rhino, run _PackageManager and search for ArchiHacks.
  2. Or install it from a terminal (assumes a default Rhino 8 installation):
    Windows (PowerShell)
    & "C:\Program Files\Rhino 8\System\Yak.exe" install ArchiHacks
  3. Or download a .yak file and drag it onto an open Rhino window.
    • ArchiHacks-1.2.10-rh8_0-win.yakWindows · Rhino 8.0
    • ArchiHacks-1.2.10-rh7_0-win.yakWindows · Rhino 7.0

Restart Rhino once the install finishes.
