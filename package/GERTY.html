How to install GERTY

  1. Click Install in Rhino to open Rhino's Package Manager with GERTY selected, or run _PackageManager inside Rhino and search for GERTY.On the computer running Rhino, run _PackageManager and search for GERTY.
  2. Or install it from a terminal (assumes a default Rhino 8 installation):
    Windows (PowerShell)
    & "C:\Program Files\Rhino 8\System\Yak.exe" install GERTY
  3. Or download a .yak file and drag it onto an open Rhino window.
    • GERTY-26.19.2.23-rh8_0-win.yakWindows · Rhino 8.0

Restart Rhino once the install finishes.
