SuperHelperRH8

Grasshopper plugin · v2.0.3.1 · updated 6/23/2024

Inactive

Replace the default help in the component right-click menu to a new Super Helper window in WPF. Super Helper window contains five tabs, namely Origin Help, URL Help, Params Help, Development Help and settings. Origin Help is the default help in Grasshopper. URL Help can specify a web page for every document object. Params Help can show document object's properties and data in calculation. Development Help can find the document object's assembly file, and its extra properties. 2.0.3.0 Notes: 修复WebHelp的网页不兼容问题； 修复开启按钮不显示问题： 删除和CapsuleRenderer插件的重复功能； 2.0.3.1 Notes: 回退依赖RhinoCommon版本；

How to install SuperHelperRH8

  1. Click Install in Rhino to open Rhino's Package Manager with SuperHelperRH8 selected, or run _PackageManager inside Rhino and search for SuperHelperRH8.On the computer running Rhino, run _PackageManager and search for SuperHelperRH8.
  2. Or install it from a terminal (assumes a default Rhino 8 installation):
    Windows (PowerShell)
    & "C:\Program Files\Rhino 8\System\Yak.exe" install SuperHelperRH8
    macOS (Terminal)
    "/Applications/Rhino 8.app/Contents/Resources/bin/yak" install SuperHelperRH8
  3. Or download a .yak file and drag it onto an open Rhino window.
    • SuperHelperRH8-2.0.3.1-rh8_8-any.yakWindows & Mac · Rhino 8.8

Restart Rhino once the install finishes.
