How to install Terra

  1. Click Install in Rhino to open Rhino's Package Manager with Terra selected, or run _PackageManager inside Rhino and search for Terra.On the computer running Rhino, run _PackageManager and search for Terra.
  2. Or install it from a terminal (assumes a default Rhino 8 installation):
    Windows (PowerShell)
    & "C:\Program Files\Rhino 8\System\Yak.exe" install Terra
  3. Or download a .yak file and drag it onto an open Rhino window.
    • Terra-1.3.31-rh8_11-win.yakWindows · Rhino 8.11
    • Terra-1.3.31-rh7_36-win.yakWindows · Rhino 7.36

Restart Rhino once the install finishes.
