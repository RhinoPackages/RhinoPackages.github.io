TRmesh

Rhino plugin · v0.2.9981.3915 · updated 9/26/2026

An easy-to-use tetrahedral mesher for Rhino3D 8/9 on Windows 10 or 11. This plugin provides both a classical Rhino plugin with a TRmesh panel, reached through a menu entry, and a Grasshopper assembly. The Grasshopper part exposes the most important, but by far not all of the functionality of the Rhino plugin. Please note that the Rhino 7 and Rhino 8 versions differ significantly. In the Rhino 8 version, a TRmesh is represented by an ordinary Rhino mesh. The main purpose of this plugin is to provide high-quality tetrahedral meshes for the TRfem heat transfer solver, but tetrahedral meshes are necessary for all other kinds of finite element analyses. TRmesh installs a menu TRMesh with a "show/hide" menu entry that allows to toggle the TRmesh panel on and off. The panel will ask you to mark input solids for meshing, as produced by the Rhino "solids" menu, and others. Type "TRmesh" and select your solids to get started.

How to install TRmesh

  1. Click Install in Rhino to open Rhino's Package Manager with TRmesh selected, or run _PackageManager inside Rhino and search for TRmesh.On the computer running Rhino, run _PackageManager and search for TRmesh.
  2. Or install it from a terminal (assumes a default Rhino 8 installation):
    Windows (PowerShell)
    & "C:\Program Files\Rhino 8\System\Yak.exe" install TRmesh
  3. Or download a .yak file and drag it onto an open Rhino window.
    • TRmesh-0.2.9981.3915-rh9_0-win.yakWindows · Rhino 9.0
    • TRmesh-0.2.9981.3915-rh8_20-win.yakWindows · Rhino 8.20

Restart Rhino once the install finishes.
