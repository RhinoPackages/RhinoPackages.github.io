CorelDRAW (.cdr / .cdt) importer AND exporter for Rhino 8 / 9 - standalone build, two commands.

ImportCDR - type the path to a .cdr/.cdt file, or press Enter to open the file picker. Shapes are rebuilt as native Rhino curves and grouped onto layers by CDR layer or by outline color (your choice at the prompt). Broken gaps between adjacent segments are repaired automatically, so contours come in closed instead of fragmented. Cubic Beziers, arcs and ellipses are kept as exact NURBS, text is converted to curves during pre-processing, and the view zooms to the imported geometry when finished (CDR drawings often sit far from the origin, which is why a successful import can look empty).

ExportCDR - writes Rhino curves back to a .cdr file. Choose to export selected curves only (default) or every curve in the document, then type a save path or use the file dialog. Layers and outline colors are preserved. Polynomial cubic Beziers are re-emitted exactly; rational curves (arcs, weighted splines) are approximated by adaptive polylines with a 0.005 mm chord-height tolerance, so a round-trip through CDR does not degrade the geometry into short line segments. Document units are converted to mm and the drawing is centred on the CDR page. Read and write share one data model, so importing a file and exporting it again is numerically verifiable.

Both commands show a status-bar progress bar for long operations and ESC cancels safely at a checkpoint (partial results from a cancelled import are kept). Every prompt follows the Rhino UI language: Chinese on a Chinese Rhino, English elsewhere. Layer names stay as data identifiers and are never translated.

REQUIREMENT (repeated): CorelDRAW, installed on the SAME computer as Rhino. This plug-in contains the CDR importer and exporter ONLY. Wentai ArtCut (.ac6) import and all sheet-metal commands are not included, and no other Zhantu plug-in is required. NOTE: the command names ImportCDR and ExportCDR are shared with SpreadAssistantIO - install only one of the two in the same Rhino. Built with the Rhino 8 SDK; Rhino 6/7 are not supported.

RELEASE: version 0.9.0 is published on the official Yak server (yak.rhino3d.com); find and install it from Rhino's Package Manager. There is no trial period and no built-in time lock; an installed copy keeps working.
