How to install signcadrhino

  1. Click Install in Rhino to open Rhino's Package Manager with signcadrhino selected, or run _PackageManager inside Rhino and search for signcadrhino.On the computer running Rhino, run _PackageManager and search for signcadrhino.
  2. Or install it from a terminal (assumes a default Rhino 7 installation):
    Windows (PowerShell)
    & "C:\Program Files\Rhino 7\System\Yak.exe" install signcadrhino
  3. Or download a .yak file and drag it onto an open Rhino window.
    • signcadrhino-261010.2.0-rh7_0-win.yakWindows · Rhino 7.0

Restart Rhino once the install finishes.
