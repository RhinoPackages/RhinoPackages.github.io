Fologram

Rhino & Grasshopper plugin · v2024.2.26 · updated 9/25/2025

Use Fologram to view and share Rhino and Grasshopper instantly in mixed reality on HoloLens 2, Meta Quest 3, iOS and Android. Geometry, layers and grasshopper parameters can be edited in real time in Fologram to create powerful tools for design, communication, collaboration and fabrication.

How to install Fologram

  1. Click Install in Rhino to open Rhino's Package Manager with Fologram selected, or run _PackageManager inside Rhino and search for Fologram.On the computer running Rhino, run _PackageManager and search for Fologram.
  2. Or install it from a terminal (assumes a default Rhino 8 installation):
    Windows (PowerShell)
    & "C:\Program Files\Rhino 8\System\Yak.exe" install Fologram
    macOS (Terminal)
    "/Applications/Rhino 8.app/Contents/Resources/bin/yak" install Fologram
  3. Or download a .yak file and drag it onto an open Rhino window.
    • Fologram-2024.2.26-rh8_0-mac.yakMac · Rhino 8.0
    • Fologram-2024.2.26-rh8_0-win.yakWindows · Rhino 8.0
