Termite

Grasshopper plugin · v1.4.0 · updated 3/10/2026

Termite is a modular, open-source slicer for Grasshopper developed for LDM 3D Printing with nozzles sizes ranging between 0.1 to 50 mm, such as the WASP 40100 LDM and Delta WASP 2040 Clay.

How to install Termite

  1. Click Install in Rhino to open Rhino's Package Manager with Termite selected, or run _PackageManager inside Rhino and search for Termite.On the computer running Rhino, run _PackageManager and search for Termite.
  2. Or install it from a terminal (assumes a default Rhino 8 installation):
    Windows (PowerShell)
    & "C:\Program Files\Rhino 8\System\Yak.exe" install Termite
    macOS (Terminal)
    "/Applications/Rhino 8.app/Contents/Resources/bin/yak" install Termite
  3. Or download a .yak file and drag it onto an open Rhino window.
    • Termite-1.4.0-rh8_0-any.yakWindows & Mac · Rhino 8.0
    • Termite-1.4.0-rh7_0-any.yakWindows & Mac · Rhino 7.0

Restart Rhino once the install finishes.
