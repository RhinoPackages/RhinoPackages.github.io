How to install flexibility

  1. Click Install in Rhino to open Rhino's Package Manager with flexibility selected, or run _PackageManager inside Rhino and search for flexibility.On the computer running Rhino, run _PackageManager and search for flexibility.
  2. Or install it from a terminal (assumes a default Rhino 8 installation):
    Windows (PowerShell)
    & "C:\Program Files\Rhino 8\System\Yak.exe" install flexibility
    macOS (Terminal)
    "/Applications/Rhino 8.app/Contents/Resources/bin/yak" install flexibility
  3. Or download a .yak file and drag it onto an open Rhino window.
    • flexibility-35.6.6-rh8_0-any.yakWindows & Mac · Rhino 8.0

Restart Rhino once the install finishes.
