robino

Rhino plugin · v0.4.2 · updated 8/17/2026

Robino is your AI agentic bridge for Rhino. It gives AI agents eyes and hands on the Rhino document: a compact DSL of 270+ chainable verbs (geometry, perception, spatial reasoning in 2D and 3D, tool authoring) over a local HTTP bridge (CLI-based). Install the /robino skill + agent kit from https://simonepeluffo.com/robino . Using the STARTER PROMPT is recommended (to be used in Claude Code, Antigravity, Codex, Cursor, or similar).

How to install robino

  1. Click Install in Rhino to open Rhino's Package Manager with robino selected, or run _PackageManager inside Rhino and search for robino.On the computer running Rhino, run _PackageManager and search for robino.
  2. Or install it from a terminal (assumes a default Rhino 8 installation):
    Windows (PowerShell)
    & "C:\Program Files\Rhino 8\System\Yak.exe" install robino
    macOS (Terminal)
    "/Applications/Rhino 8.app/Contents/Resources/bin/yak" install robino
  3. Or download a .yak file and drag it onto an open Rhino window.
    • robino-0.4.2-rh8_0-mac.yakMac · Rhino 8.0
    • robino-0.4.2-rh8_0-win.yakWindows · Rhino 8.0

Restart Rhino once the install finishes.
