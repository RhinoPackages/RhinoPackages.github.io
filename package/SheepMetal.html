SheepMetal

Grasshopper plugin · v1.2.2 · updated 10/8/2026

SheepMetal is a Grasshopper plugin for designing and preparing sheet metal parts. It converts complex BREPs into valid sheet geometry, detects features like reliefs and hems, and unrolls parts with precise control over bend parameters such as K-factor. Built for performance and production-readiness, SheepMetal includes tools for classification, validation, and visualization to streamline sheet metal workflows directly in Grasshopper. How to install SheepMetal

  1. Click Install in Rhino to open Rhino's Package Manager with SheepMetal selected, or run _PackageManager inside Rhino and search for SheepMetal.On the computer running Rhino, run _PackageManager and search for SheepMetal.
  2. Or install it from a terminal (assumes a default Rhino 8 installation):
    Windows (PowerShell)
    & "C:\Program Files\Rhino 8\System\Yak.exe" install SheepMetal
    macOS (Terminal)
    "/Applications/Rhino 8.app/Contents/Resources/bin/yak" install SheepMetal
  3. Or download a .yak file and drag it onto an open Rhino window.
    • SheepMetal-1.2.2-rh8_12-any.yakWindows & Mac · Rhino 8.12
    • SheepMetal-1.2.2-rh7_31-any.yakWindows & Mac · Rhino 7.31

Restart Rhino once the install finishes.
