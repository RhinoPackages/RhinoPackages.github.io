How to install fabricator

  1. Click Install in Rhino to open Rhino's Package Manager with fabricator selected, or run _PackageManager inside Rhino and search for fabricator.On the computer running Rhino, run _PackageManager and search for fabricator.
  2. Or install it from a terminal (assumes a default Rhino 8 installation):
    Windows (PowerShell)
    & "C:\Program Files\Rhino 8\System\Yak.exe" install fabricator
    macOS (Terminal)
    "/Applications/Rhino 8.app/Contents/Resources/bin/yak" install fabricator
  3. Or download a .yak file and drag it onto an open Rhino window.
    • fabricator-0.1.92+26202-rh8_0-any.yakWindows & Mac · Rhino 8.0

Restart Rhino once the install finishes.
