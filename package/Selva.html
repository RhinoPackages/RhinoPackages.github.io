How to install Selva

  1. Click Install in Rhino to open Rhino's Package Manager with Selva selected, or run _PackageManager inside Rhino and search for Selva.On the computer running Rhino, run _PackageManager and search for Selva.
  2. Or install it from a terminal (assumes a default Rhino 8 installation):
    Windows (PowerShell)
    & "C:\Program Files\Rhino 8\System\Yak.exe" install Selva
    macOS (Terminal)
    "/Applications/Rhino 8.app/Contents/Resources/bin/yak" install Selva
  3. Or download a .yak file and drag it onto an open Rhino window.
    • Selva-0.25.1-rh9_0-any.yakWindows & Mac · Rhino 9.0
    • Selva-0.25.1-rh8_21-any.yakWindows & Mac · Rhino 8.21

Restart Rhino once the install finishes.
