How to install BESO

  1. Click Install in Rhino to open Rhino's Package Manager with BESO selected, or run _PackageManager inside Rhino and search for BESO.On the computer running Rhino, run _PackageManager and search for BESO.
  2. Or install it from a terminal (assumes a default Rhino 7 installation):
    Windows (PowerShell)
    & "C:\Program Files\Rhino 7\System\Yak.exe" install BESO
  3. Or download a .yak file and drag it onto an open Rhino window.
    • BESO-2.4.0.0-rh7_13-win.yakWindows · Rhino 7.13

Restart Rhino once the install finishes.
