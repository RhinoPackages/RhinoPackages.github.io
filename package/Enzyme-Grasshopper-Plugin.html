How to install Enzyme-Grasshopper-Plugin

  1. Click Install in Rhino to open Rhino's Package Manager with Enzyme-Grasshopper-Plugin selected, or run _PackageManager inside Rhino and search for Enzyme-Grasshopper-Plugin.On the computer running Rhino, run _PackageManager and search for Enzyme-Grasshopper-Plugin.
  2. Or install it from a terminal (assumes a default Rhino 8 installation):
    Windows (PowerShell)
    & "C:\Program Files\Rhino 8\System\Yak.exe" install Enzyme-Grasshopper-Plugin
    macOS (Terminal)
    "/Applications/Rhino 8.app/Contents/Resources/bin/yak" install Enzyme-Grasshopper-Plugin
  3. Or download a .yak file and drag it onto an open Rhino window.
    • Enzyme-Grasshopper-Plugin-1.10.74-rh8_35-any.yakWindows & Mac · Rhino 8.35

Restart Rhino once the install finishes.
