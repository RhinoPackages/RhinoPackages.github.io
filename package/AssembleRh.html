How to install AssembleRh

  1. Click Install in Rhino to open Rhino's Package Manager with AssembleRh selected, or run _PackageManager inside Rhino and search for AssembleRh.On the computer running Rhino, run _PackageManager and search for AssembleRh.
  2. Or install it from a terminal (assumes a default Rhino 8 installation):
    Windows (PowerShell)
    & "C:\Program Files\Rhino 8\System\Yak.exe" install AssembleRh
    macOS (Terminal)
    "/Applications/Rhino 8.app/Contents/Resources/bin/yak" install AssembleRh
  3. Or download a .yak file and drag it onto an open Rhino window.
    • AssembleRh-0.1.21.9087-rh8_0-any.yakWindows & Mac · Rhino 8.0

Restart Rhino once the install finishes.
