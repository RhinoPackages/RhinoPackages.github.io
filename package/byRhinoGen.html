byRhinoGen

Rhino plugin · v1.0.4 · updated 7/5/2026

byRhinoGen is an AI-driven image generation plugin seamlessly integrated into Rhino. It allows designers to render, conceptualize, and visualize their 3D models using advanced AI text/image prompts directly within the Rhino workspace. Key Features: - Native side-panel UI for seamless AI text-to-image and image-to-image generation. - Easy account synchronization and real-time credit tracking. - Tailored for product design, architecture, and jewelry rendering workflows.

How to install byRhinoGen

  1. Click Install in Rhino to open Rhino's Package Manager with byRhinoGen selected, or run _PackageManager inside Rhino and search for byRhinoGen.On the computer running Rhino, run _PackageManager and search for byRhinoGen.
  2. Or install it from a terminal (assumes a default Rhino 8 installation):
    Windows (PowerShell)
    & "C:\Program Files\Rhino 8\System\Yak.exe" install byRhinoGen
    macOS (Terminal)
    "/Applications/Rhino 8.app/Contents/Resources/bin/yak" install byRhinoGen
  3. Or download a .yak file and drag it onto an open Rhino window.
    • byRhinoGen-1.0.4-rh8_32-any.yakWindows & Mac · Rhino 8.32

Restart Rhino once the install finishes.
