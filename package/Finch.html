How to install Finch

  1. Click Install in Rhino to open Rhino's Package Manager with Finch selected, or run _PackageManager inside Rhino and search for Finch.On the computer running Rhino, run _PackageManager and search for Finch.
  2. Or install it from a terminal (assumes a default Rhino 8 installation):
    Windows (PowerShell)
    & "C:\Program Files\Rhino 8\System\Yak.exe" install Finch
    macOS (Terminal)
    "/Applications/Rhino 8.app/Contents/Resources/bin/yak" install Finch
  3. Or download a .yak file and drag it onto an open Rhino window.
    • Finch-0.1.103-rh8_9-mac.yakMac · Rhino 8.9
    • Finch-0.1.103-rh8_9-win.yakWindows · Rhino 8.9
    • Finch-0.1.103-rh7_24-mac.yakMac · Rhino 7.24
    • Finch-0.1.103-rh7_24-win.yakWindows · Rhino 7.24

Restart Rhino once the install finishes.
