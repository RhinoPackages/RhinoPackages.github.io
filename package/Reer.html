How to install Reer

  1. Click Install in Rhino to open Rhino's Package Manager with Reer selected, or run _PackageManager inside Rhino and search for Reer.On the computer running Rhino, run _PackageManager and search for Reer.
  2. Or install it from a terminal (assumes a default Rhino 8 installation):
    Windows (PowerShell)
    & "C:\Program Files\Rhino 8\System\Yak.exe" install Reer
    macOS (Terminal)
    "/Applications/Rhino 8.app/Contents/Resources/bin/yak" install Reer
  3. Or download a .yak file and drag it onto an open Rhino window.
    • Reer-1.0.0.27-rh8_0-mac.yakMac · Rhino 8.0
    • Reer-1.0.0.27-rh8_0-win.yakWindows · Rhino 8.0
    • Reer-1.0.0.27-rh7_38-win.yakWindows · Rhino 7.38

Restart Rhino once the install finishes.
