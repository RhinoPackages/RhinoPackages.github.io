rhinogh-mcp-rhino

Rhino plugin · v0.1.1 · updated 6/16/2026

rhino-gh-mcp Rhino bridge (.rhp). Adds the _ToggleMcpService command so the rhino-gh-mcp Python MCP server can read your Rhino document — layers, selection, blocks, viewport — and run Rhino commands by name. Companion to the rhinogh-mcp-grasshopper Grasshopper plugin and the Python MCP server (Claude Desktop extension at github.com/xunliuDesign/rhino-gh-mcp). After install, launch Rhino and run _ToggleMcpService to start the listener on 127.0.0.1:9876.

How to install rhinogh-mcp-rhino

  1. Click Install in Rhino to open Rhino's Package Manager with rhinogh-mcp-rhino selected, or run _PackageManager inside Rhino and search for rhinogh-mcp-rhino.On the computer running Rhino, run _PackageManager and search for rhinogh-mcp-rhino.
  2. Or install it from a terminal (assumes a default Rhino 8 installation):
    Windows (PowerShell)
    & "C:\Program Files\Rhino 8\System\Yak.exe" install rhinogh-mcp-rhino
    macOS (Terminal)
    "/Applications/Rhino 8.app/Contents/Resources/bin/yak" install rhinogh-mcp-rhino
  3. Or download a .yak file and drag it onto an open Rhino window.
    • rhinogh-mcp-rhino-0.1.1-rh8_0-any.yakWindows & Mac · Rhino 8.0

Restart Rhino once the install finishes.
