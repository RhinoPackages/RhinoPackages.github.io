Axolotl

Grasshopper plugin · v2.0.0.0 · updated 10/29/2026

Axolotl is a plugin for volumetric modelling with signed distance functions (SDF) Axolotl is written in C# and based on RhinoCommons only, with no external dependencies. It features dozens of components organised in tabs for e.g. Primitives, Lattices, Modifications, Combinations or Meshing. The typical workflow is to build a CSG-tree by combining objects through Boolean or other operations, modify it and eventually mesh it to get the 0-level isosurface.

How to install Axolotl

  1. Click Install in Rhino to open Rhino's Package Manager with Axolotl selected, or run _PackageManager inside Rhino and search for Axolotl.On the computer running Rhino, run _PackageManager and search for Axolotl.
  2. Or install it from a terminal (assumes a default Rhino 8 installation):
    Windows (PowerShell)
    & "C:\Program Files\Rhino 8\System\Yak.exe" install Axolotl
    macOS (Terminal)
    "/Applications/Rhino 8.app/Contents/Resources/bin/yak" install Axolotl
  3. Or download a .yak file and drag it onto an open Rhino window.
    • Axolotl-2.0.0.0-rh8_0-any.yakWindows & Mac · Rhino 8.0

Restart Rhino once the install finishes.
