How to install structural-engineering

  1. Click Install in Rhino to open Rhino's Package Manager with structural-engineering selected, or run _PackageManager inside Rhino and search for structural-engineering.On the computer running Rhino, run _PackageManager and search for structural-engineering.
  2. Or install it from a terminal (assumes a default Rhino 9 WIP installation):
    Windows (PowerShell)
    & "C:\Program Files\Rhino 9 WIP\System\Yak.exe" install structural-engineering
    macOS (Terminal)
    "/Applications/Rhino 9 WIP.app/Contents/Resources/bin/yak" install structural-engineering
  3. Or download a .yak file and drag it onto an open Rhino window.
    • structural-engineering-0.1.1-alpha.7305-rh9_0-any.yakWindows & Mac · Rhino 9.0

Restart Rhino once the install finishes.
