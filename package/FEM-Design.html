FEM-Design

Grasshopper plugin · v25.2.1 · updated 9/23/2026

Grasshopper plug-in for FEM-Design 25.00.001 Toolbox to communicate with FEM-Design through StruXML allowing its users to create parametric models, run iterative analyses and create automated workflows. The open-source repository for this project can be found here: https://github.com/strusoft/femdesign-api. This toolbox contains a plenty of functions to: Create FEM-Design objects (bars, shells, covers, loads, supports, reinforcement etc.), Append objects to FEM-Design models, Run analysis, Run design calculations(RC-design, Steel-design, Timber-design), Export results, Export documentation

How to install FEM-Design

  1. Click Install in Rhino to open Rhino's Package Manager with FEM-Design selected, or run _PackageManager inside Rhino and search for FEM-Design.On the computer running Rhino, run _PackageManager and search for FEM-Design.
  2. Or install it from a terminal (assumes a default Rhino 8 installation):
    Windows (PowerShell)
    & "C:\Program Files\Rhino 8\System\Yak.exe" install FEM-Design
  3. Or download a .yak file and drag it onto an open Rhino window.
    • FEM-Design-25.2.1-rh8_0-win.yakWindows · Rhino 8.0
    • FEM-Design-25.2.1-rh7_0-win.yakWindows · Rhino 7.0

Restart Rhino once the install finishes.
