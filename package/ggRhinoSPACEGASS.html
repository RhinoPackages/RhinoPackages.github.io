How to install ggRhinoSPACEGASS

  1. Click Install in Rhino to open Rhino's Package Manager with ggRhinoSPACEGASS selected, or run _PackageManager inside Rhino and search for ggRhinoSPACEGASS.On the computer running Rhino, run _PackageManager and search for ggRhinoSPACEGASS.
  2. Or install it from a terminal (assumes a default Rhino 8 installation):
    Windows (PowerShell)
    & "C:\Program Files\Rhino 8\System\Yak.exe" install ggRhinoSPACEGASS
    macOS (Terminal)
    "/Applications/Rhino 8.app/Contents/Resources/bin/yak" install ggRhinoSPACEGASS
  3. Or download a .yak file and drag it onto an open Rhino window.
    • ggRhinoSPACEGASS-26.6.2.8-rh8_0-any.yakWindows & Mac · Rhino 8.0

Restart Rhino once the install finishes.
