Cityweft

Rhino plugin · v2.1.2 · updated 11/9/2026

Cityweft lets you integrate accurate and editable 3D models of any city or area directly into Rhino. Find sites around the world using the integrated map view and get your model in seconds: topography, buildings, trees, surfaces and more from over 150 data sources, delivered as a layered, georeferenced .3dm with block instances and NURBS terrain. Requires an API key from app.cityweft.com (active subscription or bundle). Version 2.0 supports Rhino 8 (Windows and Mac) and Rhino 7 for Mac; Rhino 7 for Windows follows in a point release.

How to install Cityweft

  1. Click Install in Rhino to open Rhino's Package Manager with Cityweft selected, or run _PackageManager inside Rhino and search for Cityweft.On the computer running Rhino, run _PackageManager and search for Cityweft.
  2. Or install it from a terminal (assumes a default Rhino 8 installation):
    Windows (PowerShell)
    & "C:\Program Files\Rhino 8\System\Yak.exe" install Cityweft
    macOS (Terminal)
    "/Applications/Rhino 8.app/Contents/Resources/bin/yak" install Cityweft
  3. Or download a .yak file and drag it onto an open Rhino window.
    • Cityweft-2.1.2-rh8_21-any.yakWindows & Mac · Rhino 8.21

Restart Rhino once the install finishes.
