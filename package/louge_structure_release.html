How to install louge_structure_release

  1. Click Install in Rhino to open Rhino's Package Manager with louge_structure_release selected, or run _PackageManager inside Rhino and search for louge_structure_release.On the computer running Rhino, run _PackageManager and search for louge_structure_release.
  2. Or install it from a terminal (assumes a default Rhino 7 installation):
    Windows (PowerShell)
    & "C:\Program Files\Rhino 7\System\Yak.exe" install louge_structure_release
    macOS (Terminal)
    "/Applications/Rhino 7.app/Contents/Resources/bin/yak" install louge_structure_release
  3. Or download a .yak file and drag it onto an open Rhino window.
    • louge_structure_release-0.3.237-rh7_19-any.yakWindows & Mac · Rhino 7.19

Restart Rhino once the install finishes.
