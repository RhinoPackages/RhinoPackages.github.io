How to install LandArchTools

  1. Click Install in Rhino to open Rhino's Package Manager with LandArchTools selected, or run _PackageManager inside Rhino and search for LandArchTools.On the computer running Rhino, run _PackageManager and search for LandArchTools.
  2. Or install it from a terminal (assumes a default Rhino 8 installation):
    Windows (PowerShell)
    & "C:\Program Files\Rhino 8\System\Yak.exe" install LandArchTools
    macOS (Terminal)
    "/Applications/Rhino 8.app/Contents/Resources/bin/yak" install LandArchTools
  3. Or download a .yak file and drag it onto an open Rhino window.
    • LandArchTools-2.0.4-rh8_0-any.yakWindows & Mac · Rhino 8.0

Restart Rhino once the install finishes.
