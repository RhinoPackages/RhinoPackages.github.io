How to install DcCalculatorV7net48

  1. Click Install in Rhino to open Rhino's Package Manager with DcCalculatorV7net48 selected, or run _PackageManager inside Rhino and search for DcCalculatorV7net48.On the computer running Rhino, run _PackageManager and search for DcCalculatorV7net48.
  2. Or install it from a terminal (assumes a default Rhino 7 installation):
    Windows (PowerShell)
    & "C:\Program Files\Rhino 7\System\Yak.exe" install DcCalculatorV7net48
    macOS (Terminal)
    "/Applications/Rhino 7.app/Contents/Resources/bin/yak" install DcCalculatorV7net48
  3. Or download a .yak file and drag it onto an open Rhino window.
    • DcCalculatorV7net48-1.0.0-rh7_9-any.yakWindows & Mac · Rhino 7.9

Restart Rhino once the install finishes.
