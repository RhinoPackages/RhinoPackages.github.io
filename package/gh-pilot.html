gh-pilot

Grasshopper plugin · v0.1.120 · updated 8/26/2026

No Rhino 8+ build

AI assistant for Grasshopper. Describe what you want in plain language — Pilot places components at final AI-chosen coordinates, wires exact ports, and writes scripts directly on your canvas. Every change is validated and applied atomically with collision and revision checks.

How to install gh-pilot

  1. Click Install in Rhino to open Rhino's Package Manager with gh-pilot selected, or run _PackageManager inside Rhino and search for gh-pilot.On the computer running Rhino, run _PackageManager and search for gh-pilot.
  2. Or install it from a terminal (assumes a default Rhino 7 installation):
    Windows (PowerShell)
    & "C:\Program Files\Rhino 7\System\Yak.exe" install gh-pilot
  3. Or download a .yak file and drag it onto an open Rhino window.
    • gh-pilot-0.1.120-rh7_0-win.yakWindows · Rhino 7.0

Restart Rhino once the install finishes.
