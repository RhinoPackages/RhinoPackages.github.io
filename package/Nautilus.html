Nautilus

Grasshopper plugin · v2.1.4.0 · updated 10/8/2026

No Rhino 8+ build

Nautilus contains components developped other the years by the author. Draw Spirals, Make perfect Maze on a mesh, Generate single line path, Wordle (random placement of objects on a 2D object), Mesh Iso Splitting , Gilbert Tessellation (2D and 3D), Differents type of reactions, Directional Reaction Diffusion, Geodesics. Notice that some components need a licence to work. This version must work with Rhino 7.10 or more, Rhino 8 and on Windows and Mac

How to install Nautilus

  1. Click Install in Rhino to open Rhino's Package Manager with Nautilus selected, or run _PackageManager inside Rhino and search for Nautilus.On the computer running Rhino, run _PackageManager and search for Nautilus.
  2. Or install it from a terminal (assumes a default Rhino 7 installation):
    Windows (PowerShell)
    & "C:\Program Files\Rhino 7\System\Yak.exe" install Nautilus
    macOS (Terminal)
    "/Applications/Rhino 7.app/Contents/Resources/bin/yak" install Nautilus
  3. Or download a .yak file and drag it onto an open Rhino window.
    • Nautilus-2.1.4.0-rh7_38-any.yakWindows & Mac · Rhino 7.38

Restart Rhino once the install finishes.
