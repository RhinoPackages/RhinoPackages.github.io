How to install OpenNest

  1. Click Install in Rhino to open Rhino's Package Manager with OpenNest selected, or run _PackageManager inside Rhino and search for OpenNest.On the computer running Rhino, run _PackageManager and search for OpenNest.
  2. Or install it from a terminal (assumes a default Rhino 8 installation):
    Windows (PowerShell)
    & "C:\Program Files\Rhino 8\System\Yak.exe" install OpenNest
    macOS (Terminal)
    "/Applications/Rhino 8.app/Contents/Resources/bin/yak" install OpenNest
  3. Or download a .yak file and drag it onto an open Rhino window.
    • OpenNest-2.96.0.0-rh9_0-mac.yakMac · Rhino 9.0
    • OpenNest-2.96.0.0-rh9_0-win.yakWindows · Rhino 9.0
    • OpenNest-2.96.0.0-rh8_0-mac.yakMac · Rhino 8.0
    • OpenNest-2.96.0.0-rh8_0-win.yakWindows · Rhino 8.0

Restart Rhino once the install finishes.
