ggRhinoIFC

Rhino & Grasshopper plugin · v26.10.2.8 · updated 10/1/2026

openBIM addon for Rhino and Grasshopper enabling IFC (Industry Foundation Class) model to be generated and exchanged to ArchiCAD, Revit, Bently, Tekla and any other BIM software with IFC capability. Also supporting BCF and IDS openBIM standards. If you have problems, reach out to support@geometrygym.com

How to install ggRhinoIFC

  1. Click Install in Rhino to open Rhino's Package Manager with ggRhinoIFC selected, or run _PackageManager inside Rhino and search for ggRhinoIFC.On the computer running Rhino, run _PackageManager and search for ggRhinoIFC.
  2. Or install it from a terminal (assumes a default Rhino 8 installation):
    Windows (PowerShell)
    & "C:\Program Files\Rhino 8\System\Yak.exe" install ggRhinoIFC
    macOS (Terminal)
    "/Applications/Rhino 8.app/Contents/Resources/bin/yak" install ggRhinoIFC
  3. Or download a .yak file and drag it onto an open Rhino window.
    • ggRhinoIFC-26.10.2.8-rh8_0-any.yakWindows & Mac · Rhino 8.0

Restart Rhino once the install finishes.
