RhinoAiMCP

Rhino plugin · v2.0.7 · updated Nov 15, 2026

Connect Rhino 7 and 8 to AI assistants via a local MCP server. Includes 14 tools, 12 built-in design skills, custom skill creation and updates with automatic backups, and Grasshopper definition creation using native components or classic GhPython scripts.

How to install RhinoAiMCP

  1. Click Install in Rhino to open Rhino's Package Manager with RhinoAiMCP selected, or run _PackageManager inside Rhino and search for RhinoAiMCP.On the computer running Rhino, run _PackageManager and search for RhinoAiMCP.
  2. Or install it from a terminal (assumes a default Rhino 8 installation):
    Windows (PowerShell)
    & "C:\Program Files\Rhino 8\System\Yak.exe" install RhinoAiMCP
    macOS (Terminal)
    "/Applications/Rhino 8.app/Contents/Resources/bin/yak" install RhinoAiMCP
  3. Or download a .yak file and drag it onto an open Rhino window.
    • RhinoAiMCP-2.0.7-rh9_1-any.yakWindows & Mac · Rhino 9.1
    • RhinoAiMCP-2.0.7-rh8_0-any.yakWindows & Mac · Rhino 8.0
    • RhinoAiMCP-2.0.7-rh7_0-any.yakWindows & Mac · Rhino 7.0

Restart Rhino once the install finishes.
